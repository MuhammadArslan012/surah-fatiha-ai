# 📖 Surah Fatiha AI

An AI-powered project focused on analyzing, understanding, and interacting with **Surah Al-Fatiha**, the opening chapter of the Qur'an.

This project demonstrates how **Artificial Intelligence, Natural Language Processing (NLP), and data analysis** can be applied to meaningful real-world content. It is designed as a learning project that bridges **technology and spirituality** while showcasing practical AI skills.

---

## 🌟 About the Surah

**Surah Al-Fatiha (ٱلْفَاتِحَة)** is the first chapter of the Qur'an, consisting of 7 verses. It is recited in every unit of Muslim prayer (Salah) and is considered a powerful supplication for:

* Guidance
* Mercy
* Support from Allah

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/MuhammadArslan012/surah-fatiha-ai.git
cd surah-fatiha-ai
```

### 2️⃣ Create Virtual Environment (Recommended)

```bash
python -m venv venv
source venv/bin/activate   # On Linux/Mac
venv\Scripts\activate      # On Windows
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Project

```bash
python app.py
```
